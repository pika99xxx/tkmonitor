# TK 达人推广监控器

本地 Chrome / Edge 扩展，用于低频巡检固定达人公开主页、识别疑似推广视频并导出 CSV。

v0.11.0 会自动滚动达人主页、分批去重收集视频，最多请求最近 100 条，并额外加载 3 条以降低置顶内容的影响。看板会显示请求数、实际加载数、滚动轮数和加载是否完整。

## 安装

1. 解压安装包。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本文件夹。
5. 在浏览器里正常登录 TikTok，然后点击扩展图标。

## 使用

在“达人名单”中每行输入一位达人：

`达人账号, 品牌名, 产品名, #活动标签`

保存后可以“扫描当前达人页”，完全不跳转；也可以“复用当前页巡检名单”，始终复用当前这个 TikTok 标签页，不再新建和关闭大量页面。

扩展优先读取页面已加载的结构化视频数据，按照真实发布时间选择最近三条，旧的置顶视频不会被误当作最新内容；同时保存播放、点赞、评论和分享。

达人账号和标签分开填写。所有达人共用同一组标签，例如 `#furniture, #homedecor`。匹配方式可以选择“满足其中之一”或“必须满足全部”。

## 注意

- 只适合少量、固定、已合作达人，不应用于大规模采集。
- 不会绕过登录、验证码、地区限制或任何访问控制。
- TikTok 页面结构变化后，可能需要更新识别规则。
- 公开视频数字来自主页卡片，可能是缩写或延迟值。
- 数据仅保存在浏览器扩展的本地存储中。
